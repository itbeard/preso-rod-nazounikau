# Ці ўмее ШІ лаяцца па-беларуску?

Прэзентацыя для заняткаў «Мовы Нанова Ўроцлаў» пра беларускую лаянку. Зробленая на аснове прэзентацыі для Прэміі Гедройця ([presa-gedroica](https://github.com/itbeard/presa-gedroica)).
Вядоўцы: Эмілія Гаўрус і Аляксей «АйЦіБарада» Картыннік.

**Жывая версія:** https://itbeard.github.io/presa-layanka/

Чысты HTML + CSS + JS, без зборкі. Шрыфты і бібліятэка QR ляжаць у рэпазіторыі, так што прэзентацыя працуе і без інтэрнэту: досыць адкрыць `index.html` у браўзеры.

## Як абнавіць

Кожны `git push` у `main` аўтаматычна выкочвае сайт на GitHub Pages (`.github/workflows/pages.yml`), гэта займае каля хвіліны.

- **Спасылка на ChatGPT-праект і QR-код:** `js/config.js` → `chatgptUrl`. QR будуецца сам. Пакуль спасылкі няма, на слайдзе бачна папярэджанне.
- **Матэрыялы на апошнім слайдзе:** файлы для спампоўкі ляжаць у `assets/files/` (прампт `skaromnik.md`, базы `praklony.pdf` і `praklony-duncy.jpg`). Спасылка на прэзентацыю для QR — `deckUrl` у `js/config.js`.
- **Час для груп:** `js/config.js` → `timerMinutes` (па змаўчанні 10).
- **Здымкі «Мова Нанова Спорт» (слайд 2):** файлы ляжаць у `assets/img/sport/`, спіс — гэта `<img>` унутры `data-slideshow` у `index.html`. Хуткасць змены — `data-interval` (мілісекунды, цяпер 2000).
- **Тэксты слайдаў і нататкі для выступоўцаў:** `index.html` (кожны слайд — гэта `<section class="slide">`, нататкі ляжаць у `<aside class="notes">`).
- **Стылі:** `css/style.css`.

## Кіраванне

| Клавіша | Дзеянне |
|---|---|
| → / Прабел / клік / свайп | далей (наступны крок або слайд) |
| ← / Backspace | назад |
| F | на ўвесь экран |
| O / Esc | агляд усіх слайдаў |
| P | акно выступоўцы: бягучы і наступны слайд, нататкі, гадзіннік |
| N | нататкі на гэтым экране |
| B або . | чорны экран |
| лічба + Enter | перайсці да слайда |
| K | відэа: паўза / прайграць |
| S / R / + / − | таймер: старт-паўза / скінуць / ±1 хвіліна |
| ? | даведка |

Пульты-клікеры (PageUp/PageDown) таксама працуюць.

**Здымкі (слайд 2)** мяняюцца самі кожныя 2 секунды і ідуць па коле, пакуль слайд на экране.

**Відэа (слайд 22)** запускаецца само, калі пераходзіце на слайд. Клік па ім або K — паўза.

**Таймер (слайд 28):** першае «далей» запускае адлік, клік па кольцы ставіць на паўзу. Калі час скончыцца, прагучыць сігнал.

**PDF на ўсялякі выпадак:** адкрыйце `index.html?static`, націсніце Cmd+P і абярыце «Захаваць як PDF».

```
js/config.js          налады (спасылка ChatGPT, таймер)
js/deck.js            навігацыя, слайд-шоў, таймер, QR, рэжым выступоўцы
js/vendor/qrcode.js   генератар QR (MIT, Kazuhiko Arase)
assets/fonts/         Inter Tight, Lora (SIL OFL)
assets/img/           фота, лагатып, арнамент
assets/img/sport/     здымкі для слайд-шоў «Мова Нанова Спорт»
presa.pdf, photo.jpg  зыходныя матэрыялы
```
