# Род назоўнікаў

Прэзентацыя для заняткаў «Мовы Нанова Уроцлаў» пра род назоўнікаў: анонсы, тэорыя, практыкаванні і заданне «Род-н-рол». Зробленая на аснове прэзентацыі для Прэміі Гедройця ([presa-gedroica](https://github.com/itbeard/presa-gedroica)).

**Жывая версія:** https://itbeard.github.io/preso-rod-nazounikau/

Чысты HTML + CSS + JS, без зборкі. Шрыфты і бібліятэка QR ляжаць у рэпазіторыі, так што прэзентацыя працуе і без інтэрнэту: досыць адкрыць `index.html` у браўзеры.

## Як абнавіць

Кожны `git push` у `main` аўтаматычна выкочвае сайт на GitHub Pages (`.github/workflows/pages.yml`), гэта займае каля хвіліны.

- **QR-код на апошнім слайдзе:** вядзе на саму прэзентацыю, каб яе можна было пагартаць пасля занятку. Спасылка — `deckUrl` у `js/config.js`, подпіс пад кодам — `deckLabel`. QR будуецца сам.
- **Здымкі «Мова Нанова Спорт» (слайд 5):** файлы ляжаць у `assets/img/sport/`, спіс кадраў — гэта `<div class="ss-frame">` унутры `data-slideshow` у `index.html`. У кадры адзін здымак або два вертыкальныя побач. Хуткасць змены — `data-interval` (мілісекунды, цяпер 2000).
- **Афішы (слайды 3, 4, 6):** у слайдзе два `<img>` з адным файлам — размыты фон і сама афіша. Памер афішы задаецца ў яе `style` (`height` для квадратных і вертыкальных, `width` для шырокіх). `data-theme="light"` — для светлых афіш, `"dark"` — для цёмных.
- **Пары ў «Правяраем» (слайды 15–22):** кожная пара — радок `<div class="pair b">` з нумарам, зыходным словазлучэннем і адказам; на слайдзе да шасці радкоў.
- **Тэксты слайдаў і нататкі для выступоўцаў:** `index.html` (кожны слайд — гэта `<section class="slide">`, нататкі ляжаць у `<aside class="notes">`).
- **Стылі:** `css/style.css`.

## Кіраванне

| Клавіша | Дзеянне |
|---|---|
| → / Прабел / клік / свайп | далей (наступны крок або слайд) |
| ← / Backspace | назад |
| F | на ўвесь экран |
| O / Esc | агляд усіх слайдаў |
| P | акно выступоўцы: бягучы і наступны слайд, нататкі, гадзіннік |
| N | нататкі на гэтым экране |
| B або . | чорны экран |
| лічба + Enter | перайсці да слайда |
| ? | даведка |

Пульты-клікеры (PageUp/PageDown) таксама працуюць.

**Здымкі (слайд 5)** мяняюцца самі кожныя 2 секунды і ідуць па коле, пакуль слайд на экране.

**«Правяраем» (слайды 15–22):** слайд адкрываецца з пустымі радкамі, кожнае «далей» адкрывае наступную пару. Калі адкрытыя ўсе — «далей» вядзе на наступны слайд.

**PDF на ўсялякі выпадак:** адкрыйце `index.html?static`, націсніце Cmd+P і абярыце «Захаваць як PDF».

## Структура

```
index.html            слайды
css/style.css         дызайн
js/config.js          налады (спасылка на прэзентацыю для QR)
js/deck.js            навігацыя, крокі, слайд-шоў, QR, рэжым выступоўцы
js/vendor/qrcode.js   генератар QR (MIT, Kazuhiko Arase)
assets/fonts/         Inter Tight, Lora (SIL OFL)
assets/img/           афішы, фота, лагатып, арнамент
assets/img/sport/     здымкі для слайд-шоў «Мова Нанова Спорт»
```
